# OpenDesign Core Orchestrator

OpenDesign transforms your coding agent into an autonomous design studio.

## The OpenDesign Agent Loop
1. **Discover & Brief**: Scope requirements (`od mcp collect_brief` or interactive dialogue). Identify artifact type: prototype, deck, live dashboard, document, or design system.
2. **Lock the Contract (`DESIGN.md`)**: Define or bind tokens (colors, type scale, border-radii, spacing, shadows). Never invent unstyled arbitrary aesthetics; anchor to the brand contract.
3. **Stream the Artifact**: Author single-page, self-contained HTML/CSS/JS artifacts with semantic markup, robust responsive layouts, and WCAG AAA contrast.
4. **Critique & Polish Pass**: Audit contrast, touch targets, layout responsiveness, and micro-interactions.
5. **Handoff & Delivery**: Export to HTML, PDF, PPTX, or component code.

## Subordinate OpenDesign Skills
- `od-design-md`: Manage and enforce DESIGN.md specifications.
- `od-artifacts-builder`: Build single-page interactive prototypes and dashboards.
- `od-brandkit` & `od-brand-guidelines`: Extract brand colors, typography, and guardrails.
- `od-design-review`: Critique visual hierarchy, accessibility, and typography.
- `od-canvas-design`: Spatial grid anchoring and component rhythm.
- `od-emil-design-eng`: Polished micro-interactions and tactile UI feel.
